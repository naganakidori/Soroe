# やらないこと（先に読む）

**提案の前にここを見ること。** 以下は検討済みで、いずれも意識して見送っている。再提案する前に、そのときの理由が今も成り立つかを確かめる。

## 初版のスコープ外

要望が出てから検討する。

- サブフォルダを含む再帰的な読み込み
- Exif の保持
- レイヤー / ブラシ / 部分選択などの対話的編集
- プリセットのインポート・エクスポート、コマンドライン実行
- トリミング、透かし・文字入れ
- RAW 現像、カラーマネジメント（ICC）

**このうち 2 件は、見送る理由が当初より重くなっている。** 当時の軽い理由だけを見て着手を判断しないこと。

- **サブフォルダの再帰**: 当初の理由は「出力時のフォルダ構造再現の判断が発生する」だった。現在は**安全ガードの見直しとセットになる**。ガードは「出力先の絶対パスがリスト内のいずれかの入力パスと一致したらスキップ」という形で成立しているが、構造を再現する出力を許すと**入力ツリーと出力ツリーが重なる形**が新たに作れる。原則 2 に直結するので、再帰だけを先に入れることはできない
- **Exif の保持**: 当初の理由は「`ImEncode` が書き出さないので、実装が必要なのは残すほう」だった。現在は**回転（適用順序 1）を足したぶん実装が増えている**。90 度回した画像に元の Orientation タグをそのまま残すと、閲覧側で二重に回る。保持するなら、回転の適用に合わせてタグを書き換える処理が要る

## 検討して採らなかった案

理由は各項の詳細に書いてある。**要約だけで判断せず、必ず参照先を読むこと。**
「詳細」の欄は [design.md](design.md) の節名を指す（バッククォートのものはコード内の識別子）。

| 案 | 採らなかった理由（要約） | 詳細 |
|---|---|---|
| 同フォルダ出力ならサフィックスを自動 ON | 触っていない設定が勝手に変わる。しかも操作の順序によっては働かない | 「安全ガード（必須）」 |
| 同名ファイルを「スキップ」する選択肢 | 上書きと結果は同じで、違うのは処理時間だけ。正しさではなく速度の最適化 | 「同名ファイルが既に存在する場合」 |
| 透過（アルファ）の保持 | 保持する経路を作ると、全調整項目にチャンネル方針が必要になる | 「透過（アルファチャンネル）」 |
| 出力形式による透過の分岐（PNG なら保持） | 同上。形式ごとに挙動が変わると説明もできない | 「透過（アルファチャンネル）」 |
| 適用順序をユーザーが並べ替える | 実装も理解も難しくなり、「分かりやすさ」の目的に反する | 「適用順序は固定」 |
| 回転を任意角度で指定させる | 傾き補正の角度は 1 枚ずつ見ないと決められない。同じ 2.3 度を 200 枚にかければ 199 枚が傾く | 「回転」 |
| 回転の候補に 0 度（＝なし）を入れる | チェックボックスと合わせて「回転しない」の言い方が 2 つできる | 「回転」 |
| 枠線を画像の外側に足す | 出力寸法が変わり、長辺 1920 の指定が 1960 になる。順序 8 の工程が順序 2 の約束を取り消す | 「枠線」 |
| 枠線の太さを短辺に対する比率にする | リサイズ後にアスペクト比が違うと揃わない。1920×1440 と 1920×1080 で 1.33 倍違う | 「枠線」 |
| 枠線の太さを長辺に対する比率にする | px と差が出るのはリサイズ無効時だけで、そのバッチは出力寸法自体が揃っていない | 「枠線」 |
| 枠線の色をフルカラーで選ばせる | ピッカーのダイアログ・16 進入力・保存形式が要る。一括処理で要る自由度に対して重すぎる | 「枠線」 |
| 枠線の上限件数を**書き出し前の見積もりに**出す | 全件の寸法を先に読む必要がある。ヘッダのみなら安い（実測 211 枚で 9ms）が、WebP が Windows のコーデック拡張に依存し、入っていない環境で黙って数え落とす | 「枠線」 |
| 彩度を HSV / Lab で行う | 8bit で色空間を往復するとそれだけで画素が変わる。輝度との線形補間なら誤差ゼロで、倍率 0 がグレースケールと一致する | 「調整項目」 |
| 二値化 ON でグレースケールを自動 ON にする | 触っていない設定が勝手に変わる。サフィックス自動 ON と同じ理由 | 「調整項目」 |
| グレースケールと二値化を排他にする | 同上。片方を押すともう片方の設定が変わる | 「調整項目」 |
| 二値化のしきい値を UI に出す | 一括処理では固定値が多くの画像で外れる。プレビューの 1 枚に合わせると他が黙って外れる | 「調整項目」 |
| 二値化のしきい値を原寸から求めてプレビューへ渡す | しきい値は明るさ等の後の画素から決まるので、スライダーを動かすたびに原寸のチェーンを流し直すことになる | 「調整項目」 |
| シャープをラプラシアンの 3×3 加算で実装する | 半径が 1px 固定でプレビューの倍率に合わせられず、書き出しと違う絵になる | 「調整項目」 |
| シャープの半径をスライダーで出す | 2 本目のスライダーを出すほどの価値がない。必要と分かってから足せる | 「調整項目」 |
| 一致テストの閾値をシャープのために一律に緩める | 緩めると他の項目の異常に気づけなくなる。空間フィルタは別の閾値を別の根拠で持つ | `MaxSharpenMeanDifference` |
| 明るさとコントラストを別々の LUT で通す | 中間で 2 度丸めが入り階調が崩れる。1 本にまとめる | 「適用順序は固定」 |
| コントラストの倍率を `1 + c/100` にする | -100 が 0 倍になり画像が消える。スライダーの下半分が使えない。`2^(c/100)` なら倍率が対称 | 「適用順序は固定」 |
| 別名の付け方を選ばせる（括弧か桁数か） | 選ばせる価値がない。`(2) (3)` に固定する | 「同名ファイルが既に存在する場合」 |
| 連番の桁数・開始番号を選ばせる | 同上。総件数から決める | 「ファイル名」 |
| PNG の圧縮率を UI に出す | 可逆なので画質は変わらない。「画質」と表示すると誤解を招く | 「形式」 |
| PNG の圧縮率を 1（OpenCV 既定）にする | 平坦な画像の利得を丸ごと捨てる。スクリーンショットで 0.090MB → 0.075MB の差 | 「形式」 |
| PNG の圧縮率を 3 にする | **折衷に見えるが最悪の選択。** zlib は 4 以上で探索方式を切り替えるため、3 では平坦画像の利得がほぼ出ない（99.8%）。実写では遅くなるだけ | 「形式」 |
| PNG の圧縮率を 6 にする | 実写 1 枚あたり **4 に対して +1.5 秒**（1 に対しては +1.7 秒）。実際のスクリーンショットで 4 との差は 83.3% と 82.5% しかない | 「形式」 |
| PNG の圧縮率を 9 にする | 実写で 1 の 10 倍の時間。サイズは 6 からさらに 2% 縮むだけ | 「形式」 |
| WebP の可逆を数値（101）で入力させる | この数字は知らなければ意味が分からない | 「形式」 |
| ドロップとフォルダ選択のモード切替 | どちらも同じリストへ追加する手段にすぎない | 「入力」 |
| 設定の項目ごとのマージ（多重起動時） | 項目単位の更新時刻と競合解決が要る。機能の価値に対して重すぎる | 「多重起動時の既知の制約」 |
| 名前付きプリセットの UI（第 2 段） | 自動保存・復元で体感価値の大半が得られている。**公開後の要望待ち**（実際に使って設定を行き来する場面が想定できなかった） | 「プリセット」 |

## 配布物に含めないもの

- **`opencv_videoio_ffmpeg4130_64.dll`（28.6MB）を zip に入れない。** OpenCvSharp の runtime パッケージに入ってくるが、**このアプリは動画を扱わないので使わない。**
  - **外す決め手はサイズではなくライセンス。** この DLL は FFmpeg で、`OpenCvSharp4.runtime.win` の README に **LGPL v2.1** と明記されている。LGPL は再リンク可能性の確保など、同梱している他のライブラリ（BSD 系・Apache-2.0 系）とは質の違う義務を伴う。**使わない機能のためにそれを背負う理由がない**
  - 静的リンクではなく**別 DLL の動的ロード**なので、消すだけで済む。OpenCV は必要になった時点で読みに行く作りで、読めなければ動画機能だけが無効になる
  - **外した状態で確認済み**（2026-08-14）。検証ハーネス全通過、アプリの起動と描画も正常。あわせて `Soroe.xml`（XML ドキュメント）と `Soroe.pdb` も配布には不要なので外す。zip は **37.5MB → 26.1MB**
  - **実際の削除はリリース手順（`tools/pack.ps1` 相当）で行う。** 手で消すと入れ忘れ・消し忘れが起きる
